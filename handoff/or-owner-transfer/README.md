# POOLMANG - תיקיית העברה לאור

עודכן: 15/05/2026

## מה יש בתיקייה

- `source/` - קוד האפליקציה להרצה ופיתוח מקומי.
- `docs/` - מצגת הדרכת צוות כקובץ HTML וכקובץ ZIP.
- `apps-script/Code.js` - קובץ Google Apps Script הנוכחי להעתקה ידנית לסקריפט.
- `build/` - גרסת build סטטית אחרונה מתוך `dist`.
- `RUN_LOCAL.md` - הוראות הרצה מקומית.
- `NOTES_FOR_OR.md` - הערות חשובות לבעלים החדש.

## איך מריצים מקומית

1. פותחים טרמינל בתוך `source`.
2. מריצים:

```bash
npm install
npm run dev
```

3. נכנסים לכתובת שהטרמינל מציג, בדרך כלל:

```text
http://127.0.0.1:5195/
```

## חשוב

- לא להעביר `node_modules` בין מחשבים. מתקינים מחדש עם `npm install`.
- אם מעדכנים `Code.js`, צריך להעתיק אותו ל־Google Apps Script ולעשות Deploy חדש.
- זרימת אישור דוחות של `SUB_OPERATOR` קיימת באפליקציה המקומית. אם רוצים אישור בין מכשירים שונים, צריך להוסיף סנכרון דרך Sheets/Apps Script.
