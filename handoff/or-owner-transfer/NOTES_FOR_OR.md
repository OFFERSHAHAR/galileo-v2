# הערות לאור - POOLMANG

## תפקידים מרכזיים

- `admin` - מנהל מלא של האפליקציה.
- `operator` - מפעיל בריכות.
- `sub_operator` / `SUB_OPERATOR` - עוזר מפעיל.

## זרימת SUB_OPERATOR

1. אדמין משייך `SUB_OPERATOR` למפעיל במסך יצירת/ניהול סדר יום.
2. ה־SUB_OPERATOR רואה את סדר היום של המפעיל המשויך.
3. ברירת מחדל: צפייה בלבד.
4. מפעיל יכול לאשר לו מילוי דוחות דרך כפתור אישור במסך הבית.
5. דוח שמולא על ידי SUB_OPERATOR לא נשלח מיד.
6. אצל המפעיל המשויך נפתחת חלונית עם פרטי הדוח.
7. המפעיל יכול לאשר שליחה או לערוך לפני שליחה.

## מגבלה קיימת

תור אישור דוחות SUB_OPERATOR נשמר כרגע בדפדפן המקומי (`localStorage`).
אם ה־SUB_OPERATOR והמפעיל עובדים ממכשירים שונים, נדרש פיתוח נוסף:

- טאב/מבנה ב־Google Sheets לדוחות ממתינים.
- פעולות Apps Script: שמירה, משיכה, אישור, מחיקה.
- סנכרון תקופתי באפליקציה.

## לא לשכוח

- לא לחשוף מפתחות API בקוד צד לקוח.
- OneSignal ו־Green API צריכים להישאר דרך Apps Script / Script Properties.
- לפני העלאה לאוויר להריץ `npm run build`.
